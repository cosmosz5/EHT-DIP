Technical Overview

Method

Forward model, network architecture, loss function, coarse-to-fine optimization schedule, and bootstrap uncertainty quantification.

1. Forward Model

The interferometric measurement equation relates the source brightness distribution \(I(l,m)\) to the complex visibility \(V(u,v)\) via the van Cittert–Zernike theorem:

\[V(u,v) = \iint I(l,m)\,e^{-2\pi i(ul+vm)}\,dl\,dm\]

For a discrete \(H \times W\) pixel image, this becomes a Non-Uniform Discrete Fourier Transform (NUDFT) evaluated at the observed \((u,v)\) baselines. The transform is implemented as a separable matrix product:

\[\mathbf{A} = I\,C_{ul}^\top,\quad \mathbf{B} = I\,S_{ul}^\top\] \[\operatorname{Re}[V_k] = \sum_h C_{vm,kh}\,A_{hk} - S_{vm,kh}\,B_{hk}\] \[\operatorname{Im}[V_k] = -\!\left(\sum_h C_{vm,kh}\,B_{hk} + S_{vm,kh}\,A_{hk}\right)\]

where \(C_{ul} = \cos(2\pi\, u_k l_j)\), \(S_{ul} = \sin(2\pi\, u_k l_j)\), precomputed once before optimization. This avoids gridding artifacts while remaining fully differentiable for backpropagation.

Closure phases — triple products of visibility phases around a baseline triangle — are used alongside amplitudes because they cancel antenna-based gain errors:

\[\psi_{ijk} = \arg\!\left(V_{ij}\cdot V_{jk}\cdot V_{ki}\right)\]

2. Network Architecture

The image is parameterized as \(\hat{I} = f_\theta(\mathbf{z})\), where \(\mathbf{z}\) is a fixed random input of shape \([1,32,H,W]\) and \(f_\theta\) is an untrained U-Net. Only the weights \(\theta\) are optimized — the fixed input prevents the network from collapsing to arbitrary solutions, acting as an implicit structural prior.

3. Loss Function

The total objective is:

\[\mathcal{L} = w_\text{amp}\,\mathcal{L}_\text{amp} + w_\text{cp}\,\mathcal{L}_\text{cp} + \lambda_\text{TSV}\,\mathcal{R}_\text{TSV} + \lambda_\text{TV}\,\mathcal{R}_\text{TV} + \lambda_\text{flux}\,\mathcal{P}_\text{flux} + \lambda_\text{comp}\,\mathcal{P}_\text{comp} + \lambda_\text{void}\,\mathcal{P}_\text{void} + \lambda_{L1}\,\mathcal{R}_{L1} + \lambda_\text{cent}\,\mathcal{P}_\text{cent}\]

Data fidelity

Both amplitude and closure phase terms use the Student's-t negative log-likelihood:

\[\mathcal{L}_t(r,\sigma) = \frac{\nu+1}{2}\log\!\left(1 + \frac{r^2}{\nu\,\sigma^2 s^2}\right)\]

with degrees of freedom \(\nu\) and optional learnable scale \(s\). As \(\nu\to\infty\) this reduces to Gaussian (least-squares); \(\nu=3\) yields heavy tails that robustly down-weight outliers. Residuals are defined as \(r=|\hat{V}|-|V_\text{obs}|\) for amplitudes and \(r=\operatorname{wrap}(\hat\psi-\psi_\text{obs})\) for closure phases, where \(\operatorname{wrap}(\cdot)\) projects to \([-\pi,\pi]\) via atan2(sin,cos).

4. Coarse-to-Fine Optimization

The reconstructed image is blurred with a separable Gaussian kernel before computing losses. The blur width decays linearly over the first blur_decay_iters iterations:

\[\sigma(t) = (1-t)\,\sigma_0 + t\,\sigma_1,\quad t = \min\!\left(1,\;\frac{\text{iter}}{\text{blur\_decay\_iters}}\right)\]

This coarse-to-fine schedule prevents premature commitment to high-frequency structure before low-frequency morphology is established.

5. Bootstrap Uncertainty Quantification

Nonparametric bootstrap resampling provides per-pixel uncertainty estimates without parametric noise assumptions. For each of \(B\) replicates:

  1. Draw weight vectors \(\mathbf{w}\in\mathbb{R}^N\) and \(\mathbf{w}_\text{cp}\in\mathbb{R}^M\) via Poisson(1) sampling (equivalent to the standard pairs bootstrap as \(N\to\infty\)) or Dirichlet\((\mathbf{1})\cdot N\) (Bayesian bootstrap).
  2. Run a short reconstruction (short_num_iter iterations) warm-started from the baseline MAP solution, applying weights as per-sample multipliers on the loss terms.
  3. Collect the ensemble \(\{\hat{I}^{(b)}\}_{b=1}^B\).

From the ensemble, per-pixel statistics are computed:

\[\bar{I} = \frac{1}{B}\sum_b \hat{I}^{(b)},\qquad \sigma_I = \operatorname{std}_b\!\left\{\hat{I}^{(b)}\right\}\]

along with the 16th and 84th percentiles for non-Gaussian posteriors. Reusing the fixed input \(\mathbf{z}\) and warm-started weights from the baseline run substantially reduces per-replicate cost.
