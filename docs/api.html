reconstruct_eht_dip

Main reconstruction function. Optimizes the U-Net weights to fit the provided interferometric data and returns the best-fit image (lowest combined data-term loss across all iterations).

python 
reconstruct_eht_dip(
    data_dict,                              # dict with u,v,vis,vsigma[,cphase,sigmacp,u1,v1,u2,v2]
    npix=128, pixel_size=5.0,              # image grid
    device=None,                            # "cuda"|"mps"|"cpu" (auto-detected if None)
    save_dir=None, save_every=None,         # periodic .npy snapshots
    amp_weight=None, cp_weight=None,        # data-term weights
    lambda_tv=None, lambda_tsv=None,        # smoothness
    use_t_amp=None, t_nu_amp=None,          # amplitude Student-t
    use_t_cp=None,  t_nu_cp=None,           # closure phase Student-t
    lambda_flux=None, target_flux=None,     # flux conservation
    lambda_compact=None, r_compact_uas=None,# compactness
    lambda_void=None,   r_void_uas=None,    # shadow exclusion
    lambda_l1=None, lambda_centroid=None,   # sparsity, centroid
    init_gaussian=None, gauss_fwhm_uas=None,# Gaussian network input init
    blur_sigma0_pix=None, blur_sigma1_pix=None, blur_decay_iters=None,
    learn_global_scale=None, global_scale_init=None,
    lr=None, num_iter=None, out_every=None,
    return_state=False,                     # if True, return dict with image + state
) -> np.ndarray | dict

Returns: np.ndarray of shape (H, W). If return_state=True, returns dict with keys "image" and "state" (containing "z" and "model_state_dict", used for bootstrap warm-starting).

reconstruct_eht_dip_bootstrap

Runs B bootstrap replicates with randomly reweighted data terms and returns ensemble statistics for per-pixel uncertainty quantification.

python 
reconstruct_eht_dip_bootstrap(
    data_dict,
    B=200,
    bootstrap_kind="poisson",   # "poisson" | "dirichlet"
    seed=12345,
    do_baseline_map=True,
    warm_start=True,
    short_num_iter=600,
    reuse_z=True,
    save_dir=None,
    save_stack=False,
    **recon_kwargs              # forwarded to reconstruct_eht_dip
) -> dict

Returns dict with keys:

KeyShapeDescription
mean(H, W)Per-pixel mean image across replicates
std(H, W)Per-pixel 1σ standard deviation
q16(H, W)16th percentile
q84(H, W)84th percentile
baseline_image(H, W)MAP image from baseline run
images(B, H, W)Full ensemble (when save_stack=False)
stack_pathstrPath to saved .npy stack (when save_stack=True)
ParameterDefaultDescription
B200Number of bootstrap replicates
bootstrap_kind'poisson'Weight distribution: 'poisson' or 'dirichlet'
do_baseline_mapTrueRun a full MAP reconstruction before bootstrap
warm_startTrueInitialize all replicates from baseline network weights
reuse_zTrueFix network input z across all replicates
short_num_iter600Optimization iterations per replicate

DIPUNet

U-Net image generator. Input: fixed random noise; output: unnormalized single-channel image. Pass through softplus externally for positivity constraint.

python 
DIPUNet(input_depth=32, base=64, depth=5, dropout=0.0)
# forward: z [B, input_depth, H, W] → [B, 1, H, W]

StudentTLoss1D

Differentiable Student's-t negative log-likelihood for 1D residuals with optional per-point sigma and sample weights.

python 
loss = StudentTLoss1D(nu=3.0, learn_sigma=False, init_sigma=1.0)
nll  = loss(r, sigma=sigma_tensor, weight=weight_tensor)
# r:      residuals [N]
# sigma:  per-point uncertainty [N] or None
# weight: per-point sample weights [N] or None
